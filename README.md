# sela License Server — سيرفر إدارة اشتراكات سيلا + الموقع الرسمي

سيرفر إدارة اشتراكات تطبيق **سيلا** لنقاط البيع (أندرويد):
إنشاء مفاتيح التفعيل وربطها بالأجهزة، **لوحة إدارة عربية احترافية بتسجيل دخول
بالبريد وكلمة المرور خلف مسار سري**، حساب **الأرباح والإيرادات**، إحصائيات
كاملة، **موقع رسمي (صفحة هبوط + صفحة تواصل) بهوية التطبيق تُدار بالكامل من
اللوحة** — جاهز للنشر على **Coolify** بملف Docker واحد.

---

## ✨ الميزات (v3)

| المجال | التفاصيل |
|---|---|
| 🔐 لوحة بمسار سري | اللوحة متاحة **فقط** على `/{ADMIN_PATH_SECRET}` — كل المسارات الأخرى (بما فيها `/admin`) تعطي **404** — لا أحد يعرف الرابط لا يصل حتى لشاشة الدخول |
| 🔑 التراخيص | إنشاء مفاتيح شهرية/ربع سنوية/سنوية/تجريبية/مخصصة · ربط أجهزة · تمديد · إيقاف · فك ربط |
| 💰 الأرباح | سعر لكل مفتاح · سجل مدفوعات كامل · تسجيل دفعات و تجديدات · إيرادات شهرية و MRR |
| 📊 الإحصائيات | لوحة معلومات برسوم بيانية · توزيع الخطط · عمليات التفعيل اليومية · الأجهزة النشطة · ما ينتهي قريباً |
| 🌐 صفحة الهبوط | موقع رسمي بهوية التطبيق (سلة + S) · عنوان ووصف ومميزات قابلة للتعديل · **رفع صور التطبيق** من اللوحة تظهر فوراً في معرض بإطار هاتف · **روابط التحميل** (جوجل بلاي / رابط مباشر APK / سطح مكتب / آب ستور) — كل رابط يُضاف ويُفعّل يظهر زره فوراً · قسم أسعار اختياري |
| 📞 صفحة التواصل | صفحة تواصل احترافية · **خيارات تواصل ديناميكية** (هاتف/واتساب/تيليجرام/بريد/رابط/مخصص) تُضاف من اللوحة وتظهر عند تفعيلها · ترتيب بالسحب (أزرار تقديم/تأخير) |
| 🛡️ مضاد الغش | ترخيص موقّع Ed25519 · فحص رجوع الساعة · قفل تلقائي عند الإيقاف |
| 📱 متجاوب كلياً | اللوحة والموقع يعملان بإتقان على الجوال والحاسوب (جداول تتحول لبطاقات، قائمة جانبية تتحول لدرج) |

## 🚀 النشر على Coolify (٣ دقائق)

1. **افتح Coolify** → مشروع → **New Resource → Application** → مستودع عام:
   ```
   https://github.com/o0lla1995-sketch/sela-license-server
   ```
2. في **Environment Variables** أضف:

   | المتغير | القيمة | ملاحظة |
   |---|---|---|
   | `ADMIN_EMAIL` | بريد المالك | أول حساب إدارة يُنشأ تلقائياً |
   | `ADMIN_PASSWORD` | كلمة مرور قوية | غيّرها لاحقاً من اللوحة |
   | `ADMIN_PATH_SECRET` | مثال: `sela-panel-x7k9m2` | **المسار السري للوحة** — اللوحة تصبح على `/{القيمة}` فقط. إن تُرك فارغاً يُولّد مسار عشوائي مرة واحدة ويُطبع في سجلات الحاوية ويُحفظ في قاعدة البيانات |
   | `LICENSE_SIGNING_PRIVATE_KEY` | القيمة من `.env.example` | **لا تغيّرها** — مطابقة للمفتاح المدمج في التطبيق |
   | `TZ` | `Asia/Jerusalem` | للتقارير الشهرية بالتوقيت المحلي |
   | `CONTACT_PHONE` / `CONTACT_WHATSAPP` / `CONTACT_TELEGRAM` / `CONTACT_EMAIL` | قيم أولية | قابلة للتعديل من اللوحة لاحقاً |
   | `ADMIN_TOKEN` | رمز قوي (اختياري) | مفتاح جذري إضافي للـ API |

3. أضف **Persistent Storage** Volume على المسار `/data`.
4. اضغط **Deploy** ثم افتح:
   - `https://رابط-تطبيقك/` → **صفحة الهبوط الرسمية**
   - `https://رابط-تطبيقك/contact` → **صفحة التواصل**
   - `https://رابط-تطبيقك/{ADMIN_PATH_SECRET}` → **لوحة الإدارة** (سرّي)

## 🧩 طريقة عمل نظام الاشتراك

```
┌────────────┐  مفتاح SELA-XXXXX-XXXXX-XXX   ┌─────────────────┐
│ تطبيق سيلا │ ─────────────────────────────► │  سيرفر الترخيص   │
│  (أندرويد) │ ◄───────────────────────────── │   (Coolify)     │
└────────────┘   ترخيص موقّع Ed25519          └─────────────────┘
```

- **التفعيل:** يُدخل التاجر المفتاح مرة واحدة مع اتصال بالإنترنت →
  السيرفر يربط المفتاح بمعرّف الجهاز ويرسل "ترخيصاً موقّعاً" بمدة الخطة.
- **العمل اليومي:** يعمل التطبيق **دون إنترنت**. التحقق عبر السيرفر يتم
  عند فتح التطبيق (بحد أقصى مرة/ساعة عند توفر النت).
- **مضاد الغش:**
  - الترخيص موقّع بتوقيع رقمي — تعديل بياناته على الجهاز يُبطله فوراً.
  - الانتهاء يُحسب من **وقت السيرفر** مثبّتاً على **عداد النظام الرتيب**
    (`elapsedRealtime`) — تغيير ساعة الهاتف للخلف **لا يُعيد** الاشتراك.
  - الانقطاع عن السيرفر أكثر من **١٠ أيام** يُقفل التطبيق حتى اتصال تحقق
    واحد ناجح، و**٣ أيام** تُظهر تنبيهاً صريحاً.
  - إيقاف المفتاح من لوحة الإدارة يُقفل كل أجهزته عند أول تحقق.

## 🗂️ لوحة الإدارة

| الصفحة | الوصف |
|---|---|
| لوحة المعلومات | إيرادات الشهر · MRR · رسوم بيانية (إيرادات ١٢ شهر، تفعيلات ٣٠ يوم، توزيع الخطط) · ما ينتهي قريباً |
| المفاتيح | إنشاء بالسعر الافتراضي للخطة · بحث وتصفية · إدارة كاملة (دفع/تمديد/إيقاف/أجهزة) |
| المدفوعات | سجل الدفوعات الكامل · دفعة يدوية · حذف · ملخصات شهرية |
| **صفحة الهبوط** | تعديل العنوان/الوصف/المميزات · **رفع صور التطبيق** وترتيبها · **روابط التحميل الأربعة** بمفاتيح تفعيل · إظهار/إخفاء الأسعار · نص التذييل و SEO |
| **التواصل** | خيارات صفحة التواصل (إضافة/تعديل/إخفاء/ترتيب/حذف) + بيانات التواصل داخل التطبيق |
| المشرفون | إضافة حسابات (مالك/مشرف) · تعطيل · إعادة تعيين كلمة مرور |
| سجل الأحداث | كل حدث أمني: دخول، تفعيل، دفع، إيقاف… |
| الإعدادات | أسعار الخطط · رمز العملة · تغيير كلمة المرور · **عرض ونسخ رابط اللوحة السري** |

## 🌐 الموقع الرسمي

| المسار | الوصف |
|---|---|
| `/` | صفحة الهبوط: أيقونة التطبيق الحالية (سلة برتقالية + S) · أزرار التحميل التي فعّلتها · المميزات · معرض صور التطبيق · الأسعار (اختياري) |
| `/contact` | بطاقات تواصل قابلة للنقر (اتصال/واتساب/تيليجرام/بريد/روابط) — تظهر كما ضبطتها من اللوحة |
| `/media/:file` | صور التطبيق المرفوعة (تُخزَّن في `/data/uploads`) |

## 🔌 الـ API

**عام (للتطبيق):** `POST /api/v1/activate` · `POST /api/v1/heartbeat` ·
`POST /api/v1/unbind` · `GET /api/v1/time|pubkey|config|health`

**عام (للموقع):** `GET /api/public/site` — كل محتوى صفحتي الهبوط والتواصل

**إدارة (جلسة/توكن):** `/api/admin/auth/login|logout|me|password` ·
`/api/admin/keys…` · `/api/admin/payments…` · `/api/admin/stats` ·
`/api/admin/analytics` · `/api/admin/admins…` · `/api/admin/audit` ·
`/api/admin/config` · `/api/admin/site` (محتوى اللاندنج + روابط التحميل) ·
`/api/admin/media…` (رفع/ترتيب/حذف صور التطبيق) ·
`/api/admin/contact-options…` (خيارات التواصل)
