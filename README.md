# sela License Server — سيرفر تفعيل اشتراكات سيلا

سيرفر إدارة اشتراكات تطبيق **sela** لنقاط البيع (أندرويد):
إنشاء مفاتيح التفعيل الشهرية/السنوية، ربطها بالأجهزة، التحقق الدوري،
الإيقاف والتمديد، لوحة إدارة عربية كاملة — جاهز للنشر على **Coolify** بملف Docker واحد.

---

## 🚀 النشر على Coolify (٣ دقائق)

1. **افتح Coolify** → مشروع جديد → **New Resource → Application**.
2. اختر **Public Repository** والصق رابط المستودع:
   ```
   https://github.com/o0lla1995-sketch/sela-license-server
   ```
3. في تبويب **Environment Variables** أضف المتغيرات التالية:

   | المتغير | القيمة | ملاحظة |
   |---|---|---|
   | `ADMIN_TOKEN` | رمز قوي من اختراعك | للدخول إلى لوحة الإدارة — **غيّره** |
   | `LICENSE_SIGNING_PRIVATE_KEY` | القيمة من ملف `.env.example` | **لا تغيّرها** — مطابقة للمفتاح المدمج في التطبيق |
   | `CONTACT_PHONE` | رقم هاتف الإدارة | يظهر داخل التطبيق |
   | `CONTACT_WHATSAPP` | رقم واتساب الإدارة | يظهر داخل التطبيق |
   | `CONTACT_EMAIL` | بريد الإدارة | يظهر داخل التطبيق |
   | `CONTACT_NOTE` | رسالة للعملاء | مثل: "لشراء الاشتراك تواصل معنا" |

4. في **Persistent Storage** أضف Volume على المسار `/data` (حتى لا تُفقد
   قاعدة البيانات والمفاتيح عند إعادة النشر).
5. اضغط **Deploy**. بعد دقيقة ستحصل على رابط السيرفر مثل:
   `https://license.xxx.example.com`
6. افتح الرابط في المتصفح → ستجد **لوحة الإدارة** — سجّل الدخول بـ `ADMIN_TOKEN`.

> **مهم:** أول ما تنشر السيرفر، انسخ رابطه وأرسله لي لأضعه داخل التطبيق
> (أو اكتبه يدوياً من شاشة التفعيل في التطبيق ← "إعدادات متقدمة").
> الخيار الافتراضي داخل التطبيق قابل للتعديل من هناك، فلا حاجة لإعادة بناء التطبيق.

## 🧩 طريقة عمل نظام الاشتراك

```
┌────────────┐  مفتاح SELA-XXXXX-XXXXX-XXX   ┌─────────────────┐
│ تطبيق sela │ ─────────────────────────────► │  سيرفر الترخيص   │
│  (أندرويد) │ ◄───────────────────────────── │   (Coolify)     │
└────────────┘   ترخيص موقّع Ed25519          └─────────────────┘
```

- **التفعيل:** يُدخل التاجر المفتاح مرة واحدة مع اتصال بالإنترنت →
  السيرفر يربط المفتاح بمعرّف الجهاز ويرسل "ترخيصاً موقّعاً" بمدة الخطة.
- **العمل اليومي:** يعمل التطبيق **دون إنترنت** (نقطة البيع أصلاً بلا نت).
  التحقق عبر السيرفر يتم عند فتح التطبيق (بحد أقصى مرة/ساعة عند توفر النت).
- **مضاد الغش:**
  - الترخيص موقّع بتوقيع رقمي — تعديل بياناته على الجهاز يُبطله فوراً.
  - الانتهاء يُحسب من **وقت السيرفر** مثبّتاً على **عداد النظام الرتيب**
    (`elapsedRealtime`) — تغيير ساعة الهاتف للخلف **لا يُعيد** الاشتراك
    ويُسجّل كمحاولة غش.
  - الانقطاع عن السيرفر أكثر من **١٠ أيام** (240 ساعة) يُقفل التطبيق حتى
    اتصال تحقق واحد ناجح، و**٣ أيام** (72 ساعة) تُظهر تنبيهاً صريحاً.
  - إيقاف المفتاح من لوحة الإدارة يُقفل كل أجهزته عند أول تحقق.

## 📡 واجهة API

### العامة (يستخدمها التطبيق)
| المسار | الوظيفة |
|---|---|
| `POST /api/v1/activate` | تفعيل مفتاح على جهاز |
| `POST /api/v1/heartbeat` | تحقق دوري (حالة/تمديد/إيقاف) |
| `POST /api/v1/unbind` | فك ربط الجهاز لنقله لجهاز آخر |
| `GET /api/v1/time` | وقت السيرفر الموثوق |
| `GET /api/v1/pubkey` | المفتاح العام للتحقق من التوقيع |
| `GET /api/v1/config` | بيانات التواصل + الخطط |
| `GET /api/v1/health` | فحص صحة الخدمة |

### الإدارة (تتطلب `Authorization: Bearer ADMIN_TOKEN`)
إنشاء مفاتيح (`POST /api/admin/keys`)، قائمة المفاتيح، تمديد/إيقاف/استعادة،
فك ربط جهاز، إحصائيات، سجل أمني، تحديث بيانات التواصل — كلها متاحة من
اللوحة الرسومية على صفحة السيرفر الرئيسية.

## 🗂 هيكل المشروع

```
sela-license-server/
├── Dockerfile            # نشر Coolify مباشرة
├── .env.example          # كل المتغيرات مع قيمها الافتراضية
├── src/
│   ├── server.js         # Express + rate limiting + توثيق الإدارة
│   ├── routes.js         # API التفعيل/النبضة/فك الربط
│   ├── admin.js          # API الإدارة
│   ├── crypto.js         # توقيع Ed25519 + توليد المفاتيح
│   ├── db.js             # SQLite (better-sqlite3) + سجل أمني
│   └── public/index.html # لوحة الإدارة العربية (RTL)
```

## 🔐 الأمان

- كل الطلبات محدودة بمعدل (60 طلب/دقيقة لكل IP).
- الترخيص لا يُعاد إصداره بوقت جديد عند إعادة التفعيل — المدة تُحفظ من أول تفعيل.
- المفتاح الخاص بالتوقيع يُقرأ من متغير البيئة فقط ولا يُطبع في أي سجل.
- سجل أمني كامل: تفعيلات، محاولات فاشلة، اشتباه إرجاع الساعة، عمليات الإدارة.
